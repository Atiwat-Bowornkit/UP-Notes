# 👤 Personas Document — UP-Notes

เอกสารนี้รวบรวมข้อมูล **Personas** ผู้ใช้งานหลักของระบบ **UP-Notes** โดยอ้างอิงจากบริบทจริงของนิสิตและบุคลากร มหาวิทยาลัยพะเยา (University of Phayao Domain)

## 1. Persona 1: Nattanon "Kankluay" (Student / Power User)
> *"ผมไม่อยากเสียเวลาครึ่งวันไล่หาไฟล์สรุปเก่าในกลุ่ม LINE หรือเดาว่าโน้ตที่เพื่อนส่งมาถูกต้องไหม... ผมแค่ต้องการแพลตฟอร์มที่เปิดเร็ว ค้นหาตามรหัสวิชาได้ทันที เพื่อเอาเวลาที่เหลือไปอ่านหนังสือและลุยโปรเจกต์"*

### 📌 5 Core Elements
1. **Personalization (รายละเอียดส่วนตัว):** นาย ณัฐนนท์ (ก้านกล้วย) อายุ 20 ปี นิสิตชั้นปีที่ 2 สาขาวิทยาการคอมพิวเตอร์ คณะ ICT มหาวิทยาลัยพะเยา อาศัยอยู่หอพักนอกฝั่งแม่กา ชอบนั่งทำงานตามร้านกาแฟรอบมหาวิทยาลัย มักเป็นหัวเรี่ยวหัวแรงในการสรุปชีทติวให้เพื่อนในกลุ่ม
2. **Job (บทบาทและหน้าที่):** นิสิตสายวิชาการ และผู้สร้างสรุปบทเรียน (Content Creator / Academic Hub)
3. **Education (การศึกษา):** ปริญญาตรี ชั้นปีที่ 2 สาขาวิทยาการคอมพิวเตอร์ คณะเทคโนโลยีสารสนเทศและการสื่อสาร มหาวิทยาลัยพะเยา
4. **Relevance (ความเกี่ยวข้องกับโปรเจกต์):** ต้องการระบบที่รวบรวมโน้ตย่อแบ่งตามรหัสวิชาของ มพ. โดยตรง มีระบบพรีวิวไฟล์ PDF/รูปภาพ สามารถอัปโหลดโน้ตย่อของตนเองเพื่อแบ่งปัน และได้รับการยอมรับจากเพื่อนๆ ผ่านคะแนนไลก์ (Likes/Ratings)
5. **Frequency of Use (ความถี่ในการใช้งาน):** ใช้งานสัปดาห์ละ 3–5 ครั้ง และใช้งานทุกวันในช่วง 2 สัปดาห์ก่อนสอบ Midterm/Final

## 2. Persona 2: Nattamon "Mint" (Student / Mobile On-the-go Learner)
> *"ช่วงนั่งรถขบเดินทางไปเรียนหรือระหว่างรอเข้าคลาส คือเวลาอ่านสรุปที่ดีที่สุด อยากได้แอปที่เปิดพรีวิวชีทสรุปในมือถือได้ลื่นๆ ไม่กินเน็ต และโหลดเก็บไว้อ่านออฟไลน์ได้ง่าย"*

### 📌 5 Core Elements
1. **Personalization (รายละเอียดส่วนตัว):** นางสาว ณัฐมล (มิ้นท์) อายุ 19 ปี นิสิตชั้นปีที่ 1 คณะบริหารธุรกิจและนิเทศศาสตร์ มหาวิทยาลัยพะเยา เดินทางในมหาวิทยาลัยด้วยรถขบ (UP Transit Bus) ทำกิจกรรมสโมสรนิสิต พกสมาร์ตโฟนติดตัวตลอดเวลา
2. **Job (บทบาทและหน้าที่):** นิสิต และนักกิจกรรมสโมสรนิสิต
3. **Education (การศึกษา):** ปริญญาตรี ชั้นปีที่ 1 มหาวิทยาลัยพะเยา
4. **Relevance (ความเกี่ยวข้องกับโปรเจกต์):** ต้องการค้นหาโน้ตย่อหมวดวิชาศึกษาทั่วไป (GE) และวิชาพื้นฐาน พรีวิวหน้าเอกสารได้ลื่นไหลบนเบราว์เซอร์มือถือ และกดดาวน์โหลดไฟล์เก็บไว้ในเครื่องเพื่ออ่านยามไม่มีสัญญาณอินเทอร์เน็ต
5. **Frequency of Use (ความถี่ในการใช้งาน):** ใช้งานสัปดาห์ละ 2–3 ครั้ง โดยเฉพาะช่วงก่อนเข้าห้องเรียนและช่วงทบทวนบทเรียนประจำสัปดาห์

## 3. Persona 3: Dr. Natthawut "Dr. Nat" (Instructor / Course Moderator)
> *"ไม่อยากเห็นนิสิตทำข้อสอบผิดเพราะไปอ่านชีทสรุปที่มีข้อมูลคลาดเคลื่อน สิ่งที่เราต้องการคือพื้นที่ที่นิสิตสามารถแบ่งปันความรู้กันได้อย่างถูกต้อง และอาจารย์สามารถเข้าไปช่วยตรวจสอบความถูกต้องได้"*

### 📌 5 Core Elements
1. **Personalization (รายละเอียดส่วนตัว):** ดร. ณัฐวุฒิ (อาจารย์นัท) อายุ 42 ปี อาจารย์ประจำสาขาวิศวกรรมซอฟต์แวร์ คณะ ICT มหาวิทยาลัยพะเยา สอนรายวิชาการพัฒนาเว็บและสถาปัตยกรรมซอฟต์แวร์ ใช้ iPad Pro ในการเตรียมการสอนและตรวจงาน
2. **Job (บทบาทและหน้าที่):** อาจารย์ผู้สอนประจำรายวิชา และผู้ทบทวนคุณภาพเนื้อหา (Course Moderator)
3. **Education (การศึกษา):** ปริญญาเอก สาขาวิศวกรรมซอฟต์แวร์
4. **Relevance (ความเกี่ยวข้องกับโปรเจกต์):** ต้องการเข้าดูสรุปบทเรียนยอดนิยมในวิชาที่ตนเองสอน เพื่อตรวจสอบว่านิสิตมีความเข้าใจคลาดเคลื่อนตรงจุดใดหรือไม่ และสามารถแนะนำโน้ตย่อคุณภาพสูงให้เป็นสื่อเสริมในชั้นเรียนได้
5. **Frequency of Use (ความถี่ในการใช้งาน):** ใช้งานเดือนละ 2–4 ครั้ง ในช่วงกลางภาคและปลายภาคเรียน
