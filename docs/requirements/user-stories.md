# 📝 User Stories Document — UP-Notes

เอกสารรวม **User Stories** จำนวน 10 รายการ สำหรับระบบ **UP-Notes** พร้อม **Acceptance Criteria (AC)** ในรูปแบบ Given/When/Then, ระดับความสำคัญ (MoSCoW) และการประมาณขนาดงาน (Estimate S/M/L)

---

## 📌 รายการ User Stories (US-01 ถึง US-10)

### Story US-01: สมัครสมาชิกและยืนยันตัวตนด้วยอีเมลมหาวิทยาลัย
* **As a** นิสิต มพ. (Kankluay / Mint)
* **I want** สมัครสมาชิกและล็อกอินเข้าสู่ระบบด้วยอีเมลมหาวิทยาลัยพะเยา (`@up.ac.th`)
* **So that** ยืนยันตัวตนว่าเป็นนิสิต มพ. จริง และได้รับสิทธิ์ใช้งานระบบอัปโหลด/กดไลก์ชีทสรุป

**Acceptance Criteria:**
- [ ] **AC1:** Given นิสิตกรอกอีเมลลงท้ายด้วย `@up.ac.th` และรหัสผ่านครบ 8 ตัวอักษรขึ้นไป When กดปุ่ม "สมัครสมาชิก" Then ระบบส่งลิงก์ยืนยันตัวตนไปยังอีเมลดังกล่าว
- [ ] **AC2:** Given นิสิตที่ยืนยันอีเมลแล้ว When กรอกอีเมลและรหัสผ่านถูกต้องแล้วกด "เข้าสู่ระบบ" Then ระบบจะล็อกอินสำเร็จและนำผู้ใช้ไปยังหน้า Dashboard หลัก
- [ ] **AC3:** Given นิสิตกรอกอีเมลโดเมนอื่นที่ไม่ใช่ `@up.ac.th` When กดปุ่ม "สมัครสมาชิก" Then ระบบแสดงข้อความแจ้งเตือน Error "กรุณาใช้อีเมลมหาวิทยาลัยพะเยาเท่านั้น"

* **Priority:** Must Have
* **Estimate:** M

### Story US-02: ค้นหาชีทสรุปบทเรียนตามรหัสวิชาและชื่อวิชา
* **As a** นิสิตผู้เตรียมสอบ (Kankluay / Mint)
* **I want** ค้นหาโน้ตย่อสรุปบทเรียนด้วยรหัสวิชา (เช่น 225311) หรือชื่อวิชา
* **So that** ค้นหาชีทสรุปตรงกับวิชาที่ตนเองกำลังเรียนได้อย่างรวดเร็ว

**Acceptance Criteria:**
- [ ] **AC1:** Given ผู้ใช้อยู่ที่หน้าค้นหาหลัก When พิมพ์รหัสวิชา `225311` แล้วกดค้นหา Then ระบบแสดงรายการโน้ตย่อทั้งหมดที่ตรงกับวิชา Software Engineering
- [ ] **AC2:** Given ผลการค้นหามีหลายรายการ When ผู้ใช้เลือกรองรับตาม "ยอดนิยมสูงสุด (Most Liked)" Then ระบบจัดเรียงรายการโน้ตย่อตามจำนวนไลก์จากมากไปน้อยทันที
- [ ] **AC3:** Given ผู้ใช้พิมพ์คำค้นหาที่ไม่พบในฐานข้อมูล When ค้นหาสำเร็จ Then ระบบแสดงหน้า Empty State แจ้งว่า "ไม่พบโน้ตย่อในวิชานี้" พร้อมปุ่มทางลัดอัปโหลด

* **Priority:** Must Have
* **Estimate:** S

### Story US-03: อัปโหลดโน้ตย่อสรุปบทเรียนพร้อมระบุรายละเอียด
* **As a** นิสิตผู้สร้างสรุปบทเรียน (Kankluay)
* **I want** อัปโหลดไฟล์เอกสาร (PDF/PNG) พร้อมใส่ชื่อเรื่อง รหัสวิชา หมวดหมู่ และคำอธิบาย
* **So that** แบ่งปันสรุปบทเรียนให้เพื่อนร่วมมหาวิทยาลัยเข้าถึงได้ง่าย

**Acceptance Criteria:**
- [ ] **AC1:** Given ผู้ใช้ล็อกอินแล้วและแนบไฟล์ PDF ขนาด 5MB พร้อมกรอกข้อมูลครบถ้วน When กดปุ่ม "เผยแพร่โน้ตย่อ" Then ระบบบันทึกข้อมูลสำเร็จและแสดงผลโน้ตย่อบนแพลตฟอร์มทันที
- [ ] **AC2:** Given ผู้ใช้พยายามแนบไฟล์ขนาด 12MB (เกิน 10MB) When เลือกไฟล์แล้ว Then ระบบแสดงแจ้งเตือนทันทีว่า "ขนาดไฟล์ต้องไม่เกิน 10MB" และไม่อนุญาตให้กดส่ง
- [ ] **AC3:** Given ผู้ใช้แนบไฟล์นามสกุล `.exe` หรือ `.zip` When เลือกไฟล์แล้ว Then ระบบแสดง Error "รองรับเฉพาะไฟล์ PDF, PNG, JPG เท่านั้น"

* **Priority:** Must Have
* **Estimate:** L

### Story US-04: พรีวิวเอกสารสรุปบทเรียนบนหน้าเบราว์เซอร์
* **As a** นิสิตอ่านสรุปผ่านมือถือ (Mint)
* **I want** เปิดพรีวิวดูตัวอย่างหน้าเอกสารโน้ตย่อบนหน้าเว็บได้ทันที
* **So that** ตรวจสอบคุณภาพและความน่าอ่านของเนื้อหาก่อนตัดสินใจดาวน์โหลดไฟล์ฉบับเต็ม

**Acceptance Criteria:**
- [ ] **AC1:** Given นิสิตกดเลือกดูการ์ดโน้ตย่อรายการหนึ่ง When หน้าเอกสารโหลดขึ้นมา Then ระบบแสดงหน้าพรีวิว 3 หน้าแรกของ PDF หรือรูปภาพเอกสารอย่างคมชัด
- [ ] **AC2:** Given นิสิตใช้งานผ่านสมาร์ตโฟน When พรีวิวเอกสาร Then หน้าจอแสดงผลแบบ Responsive ปรับขนาดให้พอดีกับหน้าจอมือถือโดยอัตโนมัติ
- [ ] **AC3:** Given นิสิตปัดหน้าพรีวิวไปมา When เลื่อนหน้า Then หน้าพรีวิวเปลี่ยนได้อย่างลื่นไหลในเวลาไม่เกิน 1 วินาที

* **Priority:** Should Have
* **Estimate:** M

### Story US-05: กดถูกใจ (Like) เพื่อส่งกำลังใจและจัดอันดับสรุปยอดนิยม
* **As a** นิสิตผู้ใช้งาน (Mint / Kankluay)
* **I want** กดปุ่มถูกใจ (Like) บนการ์ดโน้ตย่อที่ชื่นชอบ
* **So that** ให้กำลังใจผู้เขียนสรุป และช่วยจัดอันดับให้สรุปคุณภาพดีปรากฏในอันดับต้นๆ

**Acceptance Criteria:**
- [ ] **AC1:** Given นิสิตที่ล็อกอินแล้วและยังไม่เคยไลก์โน้ตนี้ When กดปุ่ม "ไลก์" Then ตัวเลขไลก์เพิ่มขึ้น 1 และไอคอนหัวใจเปลี่ยนเป็นสีแดง
- [ ] **AC2:** Given นิสิตกดปุ่มไลก์ซ้ำอีกครั้ง When กดปุ่ม Then ระบบทำการยกเลิกการไลก์ (Unlike) และตัวเลขไลก์ลดลง 1
- [ ] **AC3:** Given ผู้ใช้ที่ยังไม่ได้ล็อกอิน When กดปุ่มไลก์ Then ระบบแสดง Pop-up แจ้งเตือน "กรุณาเข้าสู่ระบบก่อนกดถูกใจ"

* **Priority:** Should Have
* **Estimate:** S

### Story US-06: ดาวน์โหลดไฟล์เอกสารสรุปบทเรียนลงเครื่อง
* **As a** นิสิตอ่านสรุปออฟไลน์ (Mint)
* **I want** กดดาวน์โหลดไฟล์สรุปฉบับเต็มเป็นไฟล์ PDF หรือรูปภาพลงในอุปกรณ์
* **So that** สามารถนำไปอ่านทบทวนแบบออฟไลน์ได้ทุกที่แม้ไม่มีสัญญาณอินเทอร์เน็ต

**Acceptance Criteria:**
- [ ] **AC1:** Given นิสิตเปิดดูหน้าโน้ตย่อวิชาหนึ่ง When กดปุ่ม "ดาวน์โหลด PDF" Then ระบบเริ่มดาวน์โหลดไฟล์ฉบับเต็มลงอุปกรณ์ทันที
- [ ] **AC2:** Given นิสิตกดดาวน์โหลดไฟล์สำเร็จ When ตรวจสอบประวัติ Then ยอดดาวน์โหลด (Download Counter) ของโน้ตย่อนั้นเพิ่มขึ้น 1
- [ ] **AC3:** Given ไฟล์เอกสารในระบบสูญหายหรือไม่สามารถเข้าถึงได้ When กดดาวน์โหลด Then ระบบแสดงแจ้งเตือน "ไม่สามารถดาวน์โหลดไฟล์ได้ในขณะนี้ กรุณาลองใหม่อีกครั้ง"

* **Priority:** Must Have
* **Estimate:** S

---

### Story US-07: จัดการและแก้ไขโน้ตย่อของตนเอง (My Notes Dashboard)
* **As a** นิสิตผู้สร้างสรุปบทเรียน (Kankluay)
* **I want** เข้าดูรายการโน้ตย่อทั้งหมดที่ตนเองเคยอัปโหลด และทำการแก้ไขหรือลบออกได้
* **So that** ปรับปรุงข้อมูลคำอธิบายให้ถูกต้อง หรือลบสรุปฉบับเก่าที่ไม่ใช้ออกไป

**Acceptance Criteria:**
- [ ] **AC1:** Given ผู้ใช้อยู่ที่หน้า "แดชบอร์ดโน้ตของฉัน" When กดปุ่ม "แก้ไข" ในรายการโน้ตย่อ แล้วเปลี่ยนคำอธิบายพร้อมกดบันทึก Then ข้อมูลอัปเดตบนหน้าเว็บทันที
- [ ] **AC2:** Given ผู้ใช้กดปุ่ม "ลบโน้ตย่อ" When ระบบแสดง Pop-up ยืนยันการลบแล้วกด "ตกลง" Then โน้ตย่อนั้นจะถูกลบออกจากฐานข้อมูลและหน้าเว็บทันที
- [ ] **AC3:** Given ผู้ใช้พยายามเข้าถึง URL หน้าแก้ไขโน้ตย่อของผู้อื่น When ระบบตรวจสิทธิ์ Then แสดง Error "403 Forbidden: คุณไม่มีสิทธิ์จัดการโน้ตรายการนี้"

* **Priority:** Should Have
* **Estimate:** M

---

### Story US-08: กรองรายการชีทสรุปตามคณะและหมวดหมู่วิชา
* **As a** นิสิตชั้นปีที่ 1 (Mint)
* **I want** กรองค้นหาโน้ตย่อตามหมวดหมู่วิชา (วิชาศึกษาทั่วไป GE / วิชาเอกบังคับ / วิชาเลือก)
* **So that** จำกัดขอบเขตการค้นหาให้เจอชีทสรุปที่ต้องการได้รวดเร็วขึ้น

**Acceptance Criteria:**
- [ ] **AC1:** Given ผู้ใช้อยู่ที่หน้าค้นหาหลัก When เลือกตัวกรองหมวดหมู่ `วิชาศึกษาทั่วไป (GE)` Then ระบบแสดงเฉพาะโน้ตย่อที่อยู่ในหมวด GE เท่านั้น
- [ ] **AC2:** Given ผู้ใช้เลือกตัวกรองหมวดหมู่ร่วมกับคำค้นหารหัสวิชา When กดค้นหา Then ระบบนำเงื่อนไขทั้งสองมาค้นหาร่วมกันแบบ AND condition
- [ ] **AC3:** Given ผู้ใช้กดปุ่ม "ล้างตัวกรอง (Clear Filters)" When กดแล้ว Then ระบบรีเซ็ตเงื่อนไขทั้งหมดและแสดงรายการโน้ตย่อทั้งหมดตามปกติ

* **Priority:** Should Have
* **Estimate:** S

### Story US-09: รายงานโน้ตย่อที่มีเนื้อหาไม่เหมาะสมหรือละเมิดลิขสิทธิ์
* **As a** อาจารย์ผู้สอนหรือนิสิต (Dr. Nat / Kankluay)
* **I want** กดรายงาน (Report) โน้ตย่อที่มีข้อมูลผิดพลาดอย่างร้ายแรง ละเมิดลิขสิทธิ์ หรือเป็นข้อสอบไม่อนุญาต
* **So that** แจ้งเตือนผู้ดูแลระบบให้เข้ามาตรวจสอบและรักษาคุณภาพของแพลตฟอร์ม

**Acceptance Criteria:**
- [ ] **AC1:** Given ผู้ใช้เปิดดูโน้ตย่อรายการหนึ่ง When กดปุ่ม "รายงานปัญหา" เลือกลักษณะปัญหา และพิมพ์เหตุผลแล้วกดส่ง Then ระบบบันทึกรายงานปัญหาสำเร็จและแสดงข้อความขอบคุณ
- [ ] **AC2:** Given โน้ตย่อรายการใดถูกรายงานเกิน 3 ครั้ง When ระบบรับรายงาน Then ระบบเปลี่ยนสถานะโน้ตย่อเป็น `Pending Review` และซ่อนจากการค้นหาชั่วคราวอัตโนมัติ
- [ ] **AC3:** Given ผู้ใช้ส่งรายงานโดยไม่เลือกเหตุผลปัญหาก่อน When กดส่ง Then ระบบแสดงแจ้งเตือน "กรุณาเลือกสาเหตุการรายงานปัญหา"

* **Priority:** Should Have
* **Estimate:** M

### Story US-10: แดชบอร์ดผู้ดูแลระบบสำหรับอนุมัติและจัดการรายงานปัญหา
* **As a** ผู้ดูแลระบบ (Admin)
* **I want** เข้าถึงหน้าแดชบอร์ด Admin เพื่อตรวจสอบโน้ตย่อที่ถูกรายงานและอนุมัติการลบไฟล์
* **So that** ควบคุมดูแลความสะอาดและความถูกต้องของเนื้อหาบนแพลตฟอร์มทั้งหมด

**Acceptance Criteria:**
- [ ] **AC1:** Given ผู้ดูแลระบบล็อกอินด้วยบัญชี Admin When เข้าหน้า `/admin/reports` Then ระบบแสดงรายการโน้ตย่อที่ถูกรายงานปัญหาทั้งหมด
- [ ] **AC2:** Given Admin ตรวจสอบรายงานแล้วพบว่าละเมิดจริง When กดปุ่ม "ลบโน้ตย่อ (Delete Note)" Then ระบบลบไฟล์ออกจาก Storage และลบข้อมูลออกจากฐานข้อมูลอย่างถาวร
- [ ] **AC3:** Given Admin ตรวจสอบแล้วพบว่าเป็นรายงานเท็จ When กดปุ่ม "ยกเลิกการรายงาน (Dismiss)" Then ระบบปลดสถานะการถูกรายงานและนำโน้ตย่อกลับมาแสดงผลตามปกติ

* **Priority:** Could Have
* **Estimate:** L
