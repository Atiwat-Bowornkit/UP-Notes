## B1 — Code Smell ที่ทีมเลือก + เหตุผล

(อ่านค่าส่วนลด + คำนวณ + ตรวจโค้ดโปรโมชัน) และมี `if` ซ้อน 4 ชั้น อ่านยากและเสี่ยงพลาดเงื่อนไข

## B2 — Fowler Quadrant: หนี้ทางเทคนิคของทีมอยู่ช่องไหน
**Prudent & Deliberate** — ทีมรู้ตัวว่าใช้วิธีเขียนเร็วเพื่อให้ทัน Milestone 1
(ตอนนั้นยังไม่มีเทสต์) และตั้งใจว่าจะกลับมาเก็บตอนมี Safety Net แล้ว → สัปดาห์นี้คือการทำตามสัญญานั้น
(ถ้าเป็น **Reckless & Deliberate** = "รู้ว่าเละแต่ไม่สน" — ทีมนี้พยายามหลีกเลี่ยง)

## B3 — Safety Net Plan (ก่อน refactor)
1. เขียน **characterization test** จับพฤติกรรมปัจจุบันก่อน (Lab 12B: 8 เทสต์)
2. ตั้ง CI + Branch Protection ให้เทสต์รันเองทุก PR ✅ (ทำในแล็บนี้แล้ว)
3. ขั้นต่อไป (W13): Extract Method ทีละขั้น รันเทสต์ทุกขั้น + commit atomic
4. ถ้าขั้นใดทำให้เทสต์แดง → `git revert` เฉพาะขั้นนั้น (ไม่ reset ย้อนทั้งงาน)
