## Lab 12B (W12) — Safety Net Sprint

- **เครื่องมือที่ใช้:** GitHub Copilot + ChatGPT
- **Prompt ที่ใช้ (2 ครั้ง):**

  1. **Brainstorm test cases**
     > "นี่คือฟังก์ชัน calculate_discount ของโปรเจกต์ผม ช่วยเสนอ test cases แบ่งเป็น happy path / edge cases / error cases พร้อมเหตุผลว่าทำไมคุ้มค่าที่จะเทสต์ ยังไม่ต้องเขียนโค้ด"

     → ผลลัพธ์: ได้ไอเดีย 9 เคส · **ทีมเลือกเอง 8 เคส** (ตัดเคสที่ทดสอบซ้ำกับตัวอื่นออก 1 เคส)
     → ทีมเขียนเทสต์เองทั้งหมด (ใช้ชื่อและค่าที่ทีมกำหนดเอง)

  2. **Debug GitHub Actions**
     > "workflow นี้ขึ้น error `ModuleNotFoundError: No module named 'src'` บน GitHub Actions แต่รันในเครื่องผ่าน ช่วยชี้ว่าสาเหตุน่าจะมาจากอะไร"

     → ผลลัพธ์: AI เสนอ 3 สาเหตุ (path, PYTHONPATH, ไฟล์ conftest ไม่ถูก commit)
     → สาเหตุจริงคือ **conftest.py ไม่ได้ถูก commit** — แก้ด้วย `git add tests/` (ทีมแก้เอง ไม่ได้ copy คำตอบ AI)

- **ส่วนที่รับจาก AI ตรงๆ (ไม่แก้):** ไม่มี
- **ตรวจสอบแล้วว่าเข้าใจทุกบรรทัดที่ส่ง:** ✅ (ทุกบรรทัดในเทสต์และ workflow อธิบายได้ในคาบ)
- **สัดส่วนงานที่เขียนเอง:** ประมาณ 90% (AI ช่วยแค่คิดเคสกับชี้จุดผิด)
