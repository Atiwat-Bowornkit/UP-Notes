## 4. Broken Window ที่เคยเจอ
* **(1) Window คืออะไร:** การเพิกเฉยต่อการจัดโครงสร้างโฟลเดอร์และการตั้งชื่อไฟล์ที่ไม่เป็นระบบ เช่น การตั้งชื่อไฟล์ว่า `test1.js`, `final_fix.js`, `index_old.js` รวมกันอยู่ใน Root Directory โดยไม่มีการแยกแยะหมวดหมู่
* **(2) ผลกระทบที่เกิดขึ้น:** เมื่อโปรเจกต์ขยายตัว การอ้างอิง Module สับสน เกิดไฟล์ที่ไม่ได้ใช้งานตกค้างอยู่เป็นจำนวนมาก สมาชิกในทีมอิมพอร์ตไฟล์ผิดเวอร์ชัน ส่งผลให้โค้ดทำงานขัดแย้งกันและยากต่อการสืบค้นประวัติใน Git
* **(3) ถ้าแก้ไขทันทีจะป้องกันอะไร:** การตกลงและจัดวางโครงสร้างโฟลเดอร์ (Folder Structure Convention) ให้ชัดเจนตั้งแต่เริ่มต้นและลบไฟล์ขยะออกทันที จะช่วยให้สมาชิกทุกคนหาไฟล์ที่ต้องการได้ง่าย ป้องกันการอิมพอร์ตผิดพลาด และทำให้คลังโค้ดสะอาดพร้อมส่งมอบงานอยู่เสมอ
