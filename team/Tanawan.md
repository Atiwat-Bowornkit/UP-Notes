## 4. Broken Window ที่เคยเจอ
* **(1) Window คืออะไร:** การไม่เขียน Documentation อธิบายวิธีติดตั้งและรันโปรเจกต์ลงใน `README.md` หรือละเลยการบันทึกข้อตกลงในการใช้งาน API สื่อสารระหว่างทีม Frontend และ Backend
* **(2) ผลกระทบที่เกิดขึ้น:** เพื่อนในทีมที่ไม่ได้รับผิดชอบส่วน Backend ไม่สามารถรันโปรเจกต์บนเครื่องตนเองได้ ต้องคอยสอบถามวิธีตั้งค่าซ้ำๆ ทางแชตส่วนตัว ทำให้การพัฒนาฝั่ง Frontend ชะงักและเกิดความล่าช้าสะสม
* **(3) ถ้าแก้ไขทันทีจะป้องกันอะไร:** การอัปเดตขั้นตอน Getting Started และ API Endpoint Specification ใน `README.md` ตั้งแต่วันแรกที่เริ่มโปรเจกต์ จะช่วยให้สมาชิกทุกคนสามารถสคลนและรันโปรเจกต์ได้ด้วยตนเองอย่างรวดเร็ว ลดเวลาการสื่อสารสับสน และทำให้โปรเจกต์ดำเนินไปได้อย่างราบรื่น
